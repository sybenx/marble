Marble 0.16.15

- Private bookmarks, mutes and other private list entries are checked before an app or site rewrites them. If several go missing, Marble asks you first. Before, only a private part that went completely empty was caught.
- Your box now compares a list with the newest version this phone knows, so it can tell what a change would lose even for a list it never signed itself. With Keykin Box 0.1.29, an app writing a list with nothing to compare it to asks first.
